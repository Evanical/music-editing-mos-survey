把所有实验音频放在这个 audio 文件夹中。

示例文件名：
mos01_source.mp3
mos01_edited.mp3
mos02_source.mp3
mos02_edited.mp3
...
pref01_source.mp3
pref01_A.mp3
pref01_B.mp3
...

然后在 index.html 的 MOS_ITEMS 和 PREFERENCE_ITEMS 中填写对应路径。

推荐：
- 使用 mp3 以减小仓库和网页加载体积；
- 文件名只使用英文字母、数字、下划线和短横线；
- 不要使用你电脑上的 C:\... 或 file:///... 本地路径；
- 上传到 GitHub 后，网页里的路径保持 audio/文件名.mp3 即可。
